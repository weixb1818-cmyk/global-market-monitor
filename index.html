17项指标的计算方法与数据来源

这里区分指标本身的定义与本项目的计算。指数、收益率和 OAS 采用供应商发布值；本项目负责筛选已完成日线、单位转换、前期／近20期变化及规则解读。来源链接同时注明原始发布机构、实际接口与尚未接入的目标源；当前实际来源和日期以各卡片为准。

A · 价格／汇率／价格指数
变化率 = (最新原值 ÷ 参考原值 − 1) × 100%，包括 DXY、两项股指、三项期货、BTC、ETH 和两个汇率。参考值为 0 时显示“—”。
B · 收益率／利差
原始单位均为百分数值：变化(bp) = (最新原值 − 参考原值) × 100。收益率水平仍显示 %；两项国债利差及 HY OAS 水平 = 原值 × 100，以 bp 显示。例如 4.00% → 4.25% 为 +25bp；利差 0.30% 为 +30bp。
C · VIX
变化(点) = 最新指数值 − 参考指数值，例如 20 → 25 为 +5 点。
前期与近20期
前期参考上一有效观测；近20期参考向前第20个有效观测，至少需要21个值。20期不是20个自然日，也不保证所有指标比较区间相同。休市／空值不补造观测；不足时显示“—”。计算使用原始精度，页面显示值另行四舍五入。

更新与日期：每天北京时间08:15调度一次，可能排队；快照生成时间不等于每项行情日期。美债、股指、VIX、OAS 和 DXY 在纽约18:00前保守排除当日数据；期货适配器在纽约17:00前排除当日数据，且须提供已收盘日期。CoinGecko 仅取已完成 UTC 日。Twelve Data 先按返回的 exchange_timezone（日界缺省 UTC）排除未完成日，再保守排除当前 UTC 日。每张卡保留独立“截至”日期；来源失败保留历史并标识失败／延迟，不把旧值改成今天。

期货口径：三项期货目前没有生产数据，也尚未确定可验证的近月换月规则。接入时必须公布近月选择、换月日期、是否复权及收盘／结算口径；换月可能产生非市场涨跌的跳变，因此这些信息确认前不会输出该序列的涨跌幅。

FRED 的利差主系列与收益率分项可能不同步。只有同一日期的两端收益率齐全时才核验利差，核验值不会替换官方主系列。已接入指标的当前来源也可在桌面悬停卡片时查看。

缺失行情的接入障碍与解决方式

DXY：需 ICE 原始指数日线授权或 Barchart DXY00 现货指数历史权限。已实现 Barchart API 适配器，配置 BARCHART_API_KEY 或现有授权源后可接入；凭证和公开展示权尚未确认。缺失时仅提供有限风险提示。

黄金 / WTI / 铜：本机富途期货请求返回行情权限不足。可先取得 CME Group 或相应 COMEX/NYMEX 行情权限，再核实近月选取、换月规则及 USD/oz、USD/bbl、USD/lb 单位；云端需自托管 runner 或可访问的授权数据接口。

USD/JPY / USD/CNH：本机 Twelve Data 账户已验证两个准确货币对各99个已完成日线，USD/CNH 为离岸人民币。公开展示与再分发授权尚待确认，线上密钥暂未配置；确认授权后即可通过 GitHub Actions Secret 接入。未使用 USD/CNY 替代。
