17项指标的计算方法与数据来源

这里区分指标本身的定义与本项目的计算。指数、收益率和 OAS 采用供应商发布值；本项目负责筛选已完成日线、单位转换、前期／近20期变化及规则解读。来源链接同时注明原始发布机构、实际接口与尚未接入的目标源；当前实际来源和日期以各卡片为准。

A · 价格／汇率／价格指数
变化率 = (最新原值 ÷ 参考原值 − 1) × 100%，包括 DXY、两项股指、黄金／WTI／铜、BTC、ETH 和两个汇率。参考值为 0 时显示“—”。
B · 收益率／利差
原始单位均为百分数值：变化(bp) = (最新原值 − 参考原值) × 100。收益率水平仍显示 %；两项国债利差及 HY OAS 水平 = 原值 × 100，以 bp 显示。例如 4.00% → 4.25% 为 +25bp；利差 0.30% 为 +30bp。
C · VIX
变化(点) = 最新指数值 − 参考指数值，例如 20 → 25 为 +5 点。
前期与近20期
前期参考上一有效观测；近20期参考向前第20个有效观测，至少需要21个值。20期不是20个自然日，也不保证所有指标比较区间相同。休市／空值不补造观测；不足时显示“—”。计算使用原始精度，页面显示值另行四舍五入。

更新与日期：每天北京时间08:15调度一次，可能排队；快照生成时间不等于每项行情日期。美债、股指、VIX、OAS 和 DXY 在纽约18:00前保守排除当日数据；期货适配器在纽约17:00前排除当日数据，且须提供已收盘日期。CoinGecko 仅取已完成 UTC 日。ECB 和 Frankfurter 当前只接收前一 UTC 日及更早的参考观测；合成序列保留各来源日期，不把全部来源均为旧日的沿用行当新观测。Twelve Data 适配器保留但当前未使用。每张卡保留独立“截至”日期；来源失败保留历史并标识失败／延迟，不把旧值改成今天。

期货口径：依据本次允许商品使用现货的要求，WTI 已明确改为 EIA 库欣现货；黄金改为 XAU/USD 合成参考价，明确不是现货收盘或期货。旧期货历史不得拼入新序列。铜仍未接入，保留原 COMEX 铜近月定义；如未来接入期货，须先确认换月和报价单位。

FRED 的利差主系列与收益率分项可能不同步。只有同一日期的两端收益率齐全时才核验利差，核验值不会替换官方主系列。已接入指标的当前来源也可在桌面悬停卡片时查看。

数据源接入情况与剩余障碍

DXY：需 ICE 原始指数日线授权或 Barchart DXY00 现货指数历史权限。已实现 Barchart API 适配器，配置 BARCHART_API_KEY 或现有授权源后可接入；凭证和公开展示权尚未确认。缺失时仅提供有限风险提示。

已接入：黄金使用 Frankfurter XAU/USD 合成参考价；WTI 使用 EIA 库欣现货；USD/JPY 使用 ECB 同日交叉参考汇率；USD/CNH 使用明确的离岸人民币合成参考汇率。均免费、无需密钥，且明确区分参考价、现货和期货。WTI 保留实际发布滞后提示。

铜：富途无行情权限；新浪对应商品有 CFD 标注；Gold API 的 HG 能返回价格，但官方文档尚未明确铜的报价单位及具体基准，免费历史还需注册密钥，因此没有凭代码或价格大小推断单位后上线。

东方财富 / 新浪 / 腾讯：已实测报价或历史接口；新浪、东方财富的站外展示需书面许可，未把无需登录访问当作免费转载授权。腾讯未核实可用的这些品种日线历史，且美元指数返回的时间较旧。详细品种、日期、额度和证据见 六项数据源核查记录 与项目 README。

合成参考序列的各上游日期保存在 数据快照 的 source_components 中。具体配置、数据源文档和权限说明见 项目 README。
