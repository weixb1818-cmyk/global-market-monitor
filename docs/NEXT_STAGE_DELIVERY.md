4. **固定阈值分析**：[分析JSON](../verification/macro-analysis.json)分别保存严格已归档输入与当前历史描述性对照，包含三项资产后续5/20期收益、入场不利变化、收盘峰谷回撤及成功/误报/漏报对照。只用信号后第一个完整收盘作为参考；缺预期交易日的窗口拒绝计量。股票按NYSE交易日、BTC按UTC自然日，不声称日内回撤或可成交收益。
5. **免费补偿及记录**：主计划08:15北京，08:45、10:15补偿检查；当天健康更新后跳过，失败可重试。记录实际创建、启动和最后作业完成时间，区分任务出现、更新/部署成功和源端是否成功。页面原提示区可提示延迟/漏跑。
6. **复现**：Python直接及传递依赖固定，Ubuntu 24.04及Playwright 1.58.2固定。每轮保存请求时间、HTTP状态、源端日期、响应哈希、修订及生成文件哈希；默认仅归档允许复用的受限ECB统计XML。新增故障测试用固定的真实归档观测作为输入，不受后来市场数据变化影响。

生产修改主要在`app.js`、`scripts/update_data.py`及新增`source_evidence.py`；分析、商品研究、调度记录和报告各有独立Python脚本；两份工作流及既有测试更新。页面结构、17项配置、指标定义和宏观阈值不变，仅收紧数据有效性边界及更新说明。为保持首屏，桌面卡片上下内边距各减2px，手机样式保留。
