# 全球市场每日观察面板 — Codex 开发规格 V1.0

> 目标：一个无需登录、每天看一眼的单页金融仪表盘。不是交易系统，不要过度工程化。
> 请直接开发可运行项目、自动更新脚本、基础测试、README；不要只提供设计建议。

## 1. 产品范围与交付

- 使用场景：每天美国市场收盘后，在电脑打开网页，1～2分钟看懂美元、利率、风险和跨资产走势。
- 页面：中文、蓝白+深海军蓝的简洁金融终端风格；桌面1440×900内尽量完整展示（无需横向滚动），移动端纵向自适应（允许竖向滚动）。
- 交付：`index.html`/CSS/JS（可采用轻量工程结构，不必React）、`scripts/update_data.py`（或等价脚本）、`data/snapshot.json`、`data/history.json`、GitHub Actions自动更新流程、最少必要的测试和README。
- 优先部署：GitHub Pages 或同等静态托管；由定时任务拉取/清洗数据，网页只读取本地已生成JSON，不能在浏览器暴露API Key。
- 低成本优先：无需数据库、用户账号、实时WebSocket、自动交易、推送、复杂AI/ML、就业/ISM/CPI数据、交易信号排名。
- 如行情源API/授权不可用：展示明确的缺失/延迟状态，不得填入随机数或以ETF/不同资产静默替代。

## 2. 固定17个指标（不得自行扩容）

| 组别 | 指标 | 推荐代码/来源 | 单位 | 提示 |
|---|---|---|---|---|
| 宏观 1 | 美元指数 DXY | 可靠市场数据源，验证原生DXY定义 | 指数点 | 不能以贸易加权美元指数冒充DXY |
| 宏观 2 | 美国2年期国债收益率 | FRED `DGS2` | % | 日变动/20期变化使用bp |
| 宏观 3 | 美国10年期国债收益率 | FRED `DGS10` | % | 名义收益率 |
| 宏观 4 | 美国10年期实际收益率 | FRED `DFII10` | % | 10年TIPS收益率，非自行用CPI相减 |
| 宏观 5 | 10Y-2Y | FRED `T10Y2Y` | bp | 10年减2年，负值为倒挂 |
| 宏观 6 | 10Y-3M | FRED `T10Y3M` | bp | 10年减3个月，负值为倒挂 |
| 宏观 7 | VIX | FRED `VIXCLS` 或等价可信收盘源 | 点 | 不代表预测涨跌方向 |
| 宏观 8 | 高收益债信用利差 HY OAS | FRED `BAMLH0A0HYM2` | bp | 这是期权调整信用利差，不是债券收益率 |
| 美股 1 | 标普500指数 | 指数本身（如 `^GSPC`，代码须验证） | 点 | 非SPY ETF |
| 美股 2 | 纳斯达克100指数 | 指数本身（如 `^NDX`，代码须验证） | 点 | 非纳斯达克综合指数 |
| 大宗 1 | 黄金 | 建议COMEX黄金近月期货；准确标注品种 | USD/oz | 不要把期货标成现货；换月需一致 |
| 大宗 2 | WTI原油 | 建议NYMEX WTI近月期货 | USD/bbl | 合约换月口径固定 |
| 大宗 3 | 铜 | 建议COMEX铜近月期货 | USD/lb | 单位必须正确 |
| 加密 1 | BTC | CoinGecko `bitcoin` 或其他可靠现货价格源 | USD | 24×7市场，日界线明确 |
| 加密 2 | ETH | CoinGecko `ethereum` 或其他可靠现货价格源 | USD | 与BTC统一口径 |
| 外汇 1 | USD/JPY | 可靠外汇日收盘/快照源 | JPY/USD | 1美元对应多少日元 |
| 外汇 2 | USD/CNH | 可靠离岸人民币汇率源 | CNH/USD | 不能以USD/CNY在岸汇率替代 |

数据源优先：美债/信用/VIX使用FRED；BTC/ETH可使用CoinGecko；其他行情必须先核验稳定可用的日线源及使用条款。外部源可通过适配器封装，切换来源不改变页面字段。

## 3. 单页布局

- 顶部：`全球市场每日观察`、快照生成时间（Asia/Tokyo）、一句话宏观状态（不超过约50汉字）、主要依据2～3条和“信号分歧/数据不足”提示。
- 下面第一组：8张宏观卡片（DXY、2Y、10Y、10Y实际、10Y-2Y、10Y-3M、VIX、HY OAS）。
- 第二组：9张跨资产卡片（美股2、大宗3、加密2、外汇2），分组标题清楚。
- 每张卡片显示：名称、最新有效值、1日或前期变化、20期变化、一句动态解读小字、数据日期（可以小号）。
- 在桌面合理使用4列或自适应网格，卡片高度紧凑；手机用1～2列；不要大型长图、营销文案、二维码。
- 可选：小型20期sparkline，但只有不影响首屏阅读时才加。无需K线、复杂图表或二级页面。
- 颜色：绿/红区分风险或价格变化时，不能机械将所有“上涨”着绿。例如DXY、VIX、实际利率、HY OAS上升常代表压力；涨跌数值本身可以使用中性色，文案作解释。避免依赖颜色唯一传达信息。

## 4. 数据时间、频率与计算口径

1. 定时在日本时间每天约09:15运行一次更新任务（GitHub cron为UTC `15 0 * * *`，在GitHub Pages场景仅作为建议）；另支持手动触发。
2. 美股/期货/外汇使用对应交易场所或数据源最新**已完成交易时段**，BTC/ETH采用前一个完整UTC自然日的收盘/快照口径；不可把未完成日K与已完成日K混为一谈。
3. FRED部分指标晚于股价发布，页面必须为每项显示`as_of`日期；总览写`本页数据截至各卡标注日期`，而不是宣称所有数字同一时刻实时。
4. 20期变化采用该**指标自身最近20个有效观测间隔**，不是生硬地减20个日历日。名称统一为“近20期”（可在说明中解释，日线大致一个月交易期；加密为20天）。20期样本不足则显示`—`。
5. 价格/指数/外汇变化：`pct_change = (current / previous - 1) * 100`，显示百分比；DXY也用百分比变化。VIX变化用点数差，不用百分比作为主要说明。
6. 利率/利差：FRED原始以百分数单位发布的数值（如4.20）在界面显示`4.20%`；变化`(current - previous) * 100`以bp显示。10Y-2Y、10Y-3M和HY OAS的**水平值**显示bp（如0.35% = +35bp）。
7. 使用FRED利差原始序列作为主数值；必要时利用同日期的DGS2/DGS10/3M辅助解释，不能跨日期相减。支持缺失值、周末、美国假日、数据更新迟滞。
8. 数据字段保留`value`,`change_1`,`change_20`,`as_of`,`source`,`status`,`unit`；支持原始历史观察点，明确`null`表示缺失。数据损坏时不得写入快照。
9. 过期策略：按美国交易日历判断，美股和利率数据连续超过2个**预期发布交易日**无更新时标`数据延迟`；加密超过36小时未取得有效新日值标延迟。若核心宏观信号不足，顶部显示`无法可靠判断`并说明缺哪些数据；不得沿用昨日状态伪装为今天结果。市场正常休市无需虚报故障。
10. 每次更新失败应保留上一次有效快照，并显式展示快照时间/单卡时间；记录日志；不因一个提供商失败导致整页空白。

## 5. 宏观状态识别逻辑（解释型规则V1，阈值可配置，不声称科学预测）

### 5.1 计算输入

- `dxy20` = DXY最近20期百分比变化。
- `real20bp` = 10年实际利率最近20期变动bp。
- `twoYear20bp` = 2Y最近20期变动bp。
- `hy20bp` = HY OAS最近20期变动bp。
- `vix20pt` = VIX最近20期点数变化。
- `hyNow` = HY OAS当前bp；`vixNow` = VIX当前值。
- 利差和10Y本身用于解释，不独立加权进入风险判断，以免重复计数。

### 5.2 预设阈值（均为可调整的启发式初值，未回测验证）

- 美元显著走强：`dxy20 >= +1.0%`；显著走弱：`dxy20 <= -1.0%`。
- 实际利率显著上行：`real20bp >= +15`；显著下行：`real20bp <= -15`。
- 信用风险走高：`hy20bp >= +25`；特别关注高位`hyNow >= 450bp`。
- 波动风险走高：`vix20pt >= +3`；特别关注高位`vixNow >= 25`。
- 短端显著下行：`twoYear20bp <= -25`。
- 若要判断“压力扩散”，高位触发条件应额外验证持续或走坏（不能因为高位但大幅回落，就写“正在扩散”）。

### 5.3 分类（按顺序匹配，最终只显示一个主状态）

1. **金融压力扩散**：`hy20bp >= +25`且`vix20pt >= +3`。输出“信用利差与波动率共同上升，市场防御需求增强”。
2. **增长担忧定价**：`twoYear20bp <= -25`且(`hy20bp >= +25`或`vix20pt >= +3`)。输出“短端利率下行，但信用或波动信号恶化；降息预期未必利好风险资产”。
3. **金融条件趋紧**：`dxy20 >= +1.0`且`real20bp >= +15`。输出“美元和实际利率同步上行，估值及融资环境压力增加”。
4. **温和宽松**：`dxy20 <= -1.0`且`real20bp <= -15`且`hy20bp < +25`且`vix20pt < +3`且`hyNow < 450`且`vixNow < 25`。输出“美元和实际利率下降，信用及波动风险尚未同步恶化”。
5. **中性/信号分歧**：其余情形。输出哪些信号互相矛盾，禁止强行看多/看空。

上列属于对金融市场价格信号的分类，不能称作对GDP/经济衰退的精准预测。规则仅为V1，所有阈值放`config`文件而非硬编码，便于调整。

### 5.4 必须执行的约束

- 若用于上述规则的DXY、实际利率、2Y、HY OAS、VIX有任一关键20期数据缺失/超期，应显示`数据不足：暂不判断`，不猜测、不复用旧结论。
- 顶部必须包含“状态 + 为什么 + 不确定因素”：如“金融条件趋紧｜美元与实际利率同步上升；信用利差暂未显著恶化”。
- 即使宏观判断偏宽松，也不输出必涨、买入、做多、做空等投资指令。
- 10Y-2Y和10Y-3M作为**解释项**，不可将“倒挂恢复”直接写成“经济复苏”或“股市必涨”。

## 6. 每张卡片的小字动态解读规则（模板，不需要大模型）

- DXY：近20期显著上涨 -> “美元走强，关注全球风险资产压力”；显著下跌 -> “美元走弱，外部美元压力可能缓解”；否则“美元阶段性震荡”。
- 2Y：大幅下降 -> “短端利率下行，市场可能增加降息定价”；大幅上升 -> “短端利率上行，政策利率预期偏紧”；否则“短端利率变化有限”。
- 10Y：显著上行 -> “长期融资及估值折现压力上升”；显著下降 -> “长期收益率回落，需辨别增长预期与避险驱动”；否则“长端利率基本稳定”。
- 10Y实际：上涨 -> “实际利率上行，黄金及高估值资产或承压”；下降 -> “实际利率下行，相关估值压力缓解”。
- 10Y-2Y：水平<0 -> “仍处倒挂”；水平>=0 -> “当前为正利差”；20期上升>=15bp再补“曲线变陡”，下降<=-15bp补“曲线变平”。当曲线变陡时通过2Y/10Y变化解释：短端下降更快/长端上升更快/混合驱动；不能直接提示看多。
- 10Y-3M：同样区分倒挂/正常及变陡/变平，解读“期限结构仍偏异常/已恢复正斜率，不等于衰退风险消失”；有足够同日数据时解释3M与10Y驱动。
- VIX：20期上升>=3点 -> “波动率预期上升，风险偏好降温”；下降<=-3点 -> “波动预期回落”；否则“波动预期变化有限”。
- HY OAS：20期扩大>=25bp -> “信用风险溢价扩大，关注风险扩散”；收窄<=-25bp -> “信用风险溢价回落”；否则“信用市场相对稳定”。
- S&P 500 / Nasdaq 100：20期涨跌显著时描述趋势；纳指只说明成长/科技权重较高，不强行因果归因。
- 黄金：描述20期方向，必要时补充“需结合实际利率与美元判断”。
- WTI / 铜：描述20期方向，分别提示能源供需/工业需求，但不直接断言经济周期。
- BTC / ETH：描述20期价格趋势，不将其直接解释为全球流动性改善的证明。
- USD/JPY / USD/CNH：上涨含义必须写对，即“美元相对日元/离岸人民币升值”；下降则反之。
- 数据缺失/过期：小字改成“数据暂未更新，截至YYYY-MM-DD”，不得生成方向性解读。
- 每条小字尽量控制在18～35汉字之间；不以“必然”“确定”“买入信号”措辞。

## 7. 最简技术实施

- 优选：静态HTML + CSS + 原生JavaScript（或小型前端打包工具），不建React服务端、数据库、身份系统。
- Python脚本定时读取行情，做日期/单位统一、变化计算、状态识别并生成 JSON；浏览器只负责呈现。
- FRED：优先使用合规、稳定的数据获取方式（官方API Key可存GitHub Secrets，或经验证可用的CSV下载）。CoinGecko：使用其官方Demo API并把Key存Secrets。其他市场源若选用非官方/抓取接口，在README标注稳定性、使用条款与替代方案，不应把不稳定源说成官方保证。
- 数据流程：取数 -> 校验原始值与时区 -> 对齐单指标历史 -> 计算变化 -> 运行宏观状态规则 -> 生成JSON -> 发布静态网页。
- 仓库应包含`config`阈值、指标配置和数据源映射，便于以后不改主代码就能调整。

## 8. 测试与验收（必须）

1. 17个指标齐全且名称、单位正确；页面默认没有模拟数字冒充实盘。
2. `DGS10=4.30%`、`DGS2=4.00%`时，10Y-2Y显示`+30bp`；`DGS10=4.00%`、`DGS2=4.50%`时显示`-50bp`；如官方利差与同日计算差超过合理误差，记录告警。
3. `HY OAS=3.20%`应显示`320bp`；利差、收益率变化不显示成`+0.25%`与`+25bp`混淆。
4. `USD/CNH`涨表示美元升值、离岸人民币贬值；`USD/JPY`同理。
5. DXY+1.5%、实际利率+20bp、信用稳定 -> `金融条件趋紧`；DXY-1.5%、实际利率-20bp、信用/VIX稳定且处于低风险水平 -> `温和宽松`。
6. HY OAS+40bp、VIX+5点 -> `金融压力扩散`，即使DXY和实际利率下降也不允许误判成宽松。
7. 2Y下降40bp且HY OAS+30bp、VIX稳定 -> `增长担忧定价`；缺少关键数据时 -> `数据不足：暂不判断`。
8. 利差由-20bp升至+10bp，只解释为“倒挂结束/曲线变陡”，不标为“经济复苏”。
9. 更新失败、美国节假日、周末、市场不同步时页面不闪退，并准确标注每卡日期和快照生成时间。
10. 页面在1440×900桌面可快速扫读；手机上文字不溢出、没有横向滚动；指标卡小字可读。
11. README包含本地运行、数据源和许可证/限制、密钥设置、自动任务设置、手动刷新、故障排查步骤。

## 9. 交付优先顺序

P0：全部17卡片 + 正确数据与日期 + 自动更新 + 宏观状态和小字解读。
P1：20期迷你走势图、来源点击查看、状态解释弹层（仅在布局充裕时做）。
暂不做：历史回测、综合分数、复杂模型、经济数据看板、登录、邮件/通知、交易执行。

请先实现P0并运行测试；如发现数据源无法稳定提供真实价格，请在最终报告中列出缺失项、可用替代数据源和具体阻碍，不能无说明地用假数据凑齐。
